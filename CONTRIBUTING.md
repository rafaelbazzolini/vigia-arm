# Contribuir

Mantenha o projeto independente. Use especificações públicas e dependências com licenças compatíveis. Não inclua código descompilado, SDKs proprietários ou recursos de outros aplicativos.

Para alterações de vídeo/rede, acrescente um caso ao equipamento simulado ou descreva o teste manual em hardware. Para alterações de backup, preserve testes de round-trip, senha incorreta, integridade, validação e restauração transacional.

Não envie senhas, perfis reais, IPs públicos, números de série ou imagens de câmeras em issues/PRs. Use apenas equipamentos e redes autorizados.
